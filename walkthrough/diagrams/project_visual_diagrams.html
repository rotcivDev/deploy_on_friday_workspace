How To Read

Purpose: this document gives visual entry points into the project. It does not replace the detailed walkthroughs; it helps readers understand the product, modules, flows, boundaries, and delivery model quickly.

Each diagram is grouped by the mentor role that owns the concern. The same source-of-truth rule applies throughout: domain behavior comes first, then architecture, data, infrastructure, and delivery tools protect that behavior.

This document uses MermaidJS. If diagrams do not render in a restricted/offline browser, the Mermaid source remains visible enough to inspect and can be pasted into any Mermaid renderer.
