Git Workflow Refinement Guide: v0.1 Prototype

This guide aligns repository hygiene with the HTML walkthrough migration and the v0.1 delivery plan. It is a support artifact only and does not require edits under protected production source directories.

1. Review Summary

Second Review: Source-of-Truth Alignment. Git workflow should make domain decisions traceable. Documentation migrations, backlog changes, Docker/Compose updates, and architecture decisions should be committed in reviewable slices with Conventional Commit messages that name the product/domain reason, not just the tool changed.

The repository now treats human-facing walkthrough documents as HTML artifacts. Git hygiene should make that format easy to review while preserving executable support files such as SQL seeds in their native form.

Recommendation: use focused docs: commits for documentation migrations, keep generated HTML and removed Markdown in the same review, and verify that no source-tree files under domain/, application/, infrastructure/, server/, client/, or shared/ are touched by mentorship tasks.

2. v0.1 Git Scope

In Scope

  • Repository status review before and after documentation migrations.
  • Conventional Commit guidance for HTML walkthrough work.
  • Review checklist for removed stale Markdown files.
  • Guidance for ignoring local artifacts such as .env, build/, and generated simulation logs when needed.

Out Of Scope

  • Destructive Git operations without explicit approval.
  • Reverting unrelated user or agent work.
  • Modifying protected production source directories.

4. Suggested Review Workflow

git status --short
git diff --stat
git diff -- walkthrough AGENTS.md .agent/skills
rg -n "\.md" walkthrough AGENTS.md .agent/skills
rg --files walkthrough | sort

Do not run destructive cleanup commands for unrelated files. If stale Markdown files under walkthrough/ are intentionally removed, verify that matching .html files exist first.

5. Readiness Checklist

  • All human-facing walkthrough refinement guides are HTML.
  • SQL seed templates remain SQL.
  • AGENTS registry links point to HTML walkthrough files.
  • Mentor profiles mention the HTML walkthrough output policy.
  • Product Manager backlog HTML was compiled after the role refinements.
  • No protected production source directories were modified.
