T07 Implementation Plan: Build Encounter Deck From Loaded Content

Intent

Goal: Implement the Encounter deck structure, draw mechanics, discard pile handling, and deterministic reshuffling using the RNG module from T06.

A card deck needs separate arrays representing the "draw pile" and the "discard pile". When the draw pile runs dry, the discard pile must be shuffled and returned to the draw pile deterministically. This task builds the domain logic for these operations.

Implementation Story

Source backlog item: T07, R2, AR3, DB1, GD1.

Domain behavior served: Initiating, drawing from, discarding into, and reshuffling the Encounter deck during a match loop.

User-visible outcome served: Players draw random encounters deterministically. If the deck runs out, it shuffles and allows continued play.

Boundaries touched by the human: domain/deck.h, domain/deck.c, tests/domain/test_deck.c.

Out of scope: Live DB queries inside domain/ (only load definitions loaded from application layer).

Deck Behavior Rules

  • Shuffling: Uses the Knuth/Fisher-Yates shuffle algorithm with the RNG struct.
  • Drawing: Returns the top card. If empty, triggers a reshuffle from the discard pile, then draws. If both are empty, return an empty indicator or error.
  • Discarding: Pushes card to the discard pile array.

Example Deck Implementation

Human-created file: domain/deck.c

#include "deck.h"
#include <string.h>

void game_deck_init(game_deck_t *deck) {
    if (deck) {
        deck->draw_count = 0;
        deck->discard_count = 0;
    }
}

void game_deck_add_card(game_deck_t *deck, const game_card_def_t *card) {
    if (deck && card && deck->draw_count < MAX_DECK_CARDS) {
        deck->draw_pile[deck->draw_count++] = card;
    }
}

void game_deck_shuffle(game_deck_t *deck, game_rng_t *rng) {
    if (!deck || !rng || deck->draw_count <= 1) return;
    for (int i = deck->draw_count - 1; i > 0; i--) {
        uint32_t j = game_rng_range(rng, 0, i);
        const game_card_def_t *temp = deck->draw_pile[i];
        deck->draw_pile[i] = deck->draw_pile[j];
        deck->draw_pile[j] = temp;
    }
}

const game_card_def_t *game_deck_draw(game_deck_t *deck, game_rng_t *rng) {
    if (!deck) return NULL;
    if (deck->draw_count == 0) {
        if (deck->discard_count == 0) {
            return NULL; // completely empty
        }
        // Reshuffle discard into draw
        for (int i = 0; i < deck->discard_count; i++) {
            deck->draw_pile[i] = deck->discard_pile[i];
        }
        deck->draw_count = deck->discard_count;
        deck->discard_count = 0;
        game_deck_shuffle(deck, rng);
    }
    return deck->draw_pile[--deck->draw_count];
}

void game_deck_discard(game_deck_t *deck, const game_card_def_t *card) {
    if (deck && card && deck->discard_count < MAX_DECK_CARDS) {
        deck->discard_pile[deck->discard_count++] = card;
    }
}

Example Deck Test

Human-created file: tests/domain/test_deck.c

#include "deck.h"
#include "rng.h"
#include "content.h"
#include <assert.h>
#include <string.h>

int main(void) {
    game_card_def_t card1 = {"Encounter A", CARD_MONSTER, 5, 0, 1};
    game_card_def_t card2 = {"Encounter B", CARD_CURSE, 0, 0, 1};

    game_deck_t deck;
    game_deck_init(&deck);
    game_deck_add_card(&deck, &card1);
    game_deck_add_card(&deck, &card2);

    game_rng_t rng;
    game_rng_init(&rng, 123);

    game_deck_shuffle(&deck, &rng);

    const game_card_def_t *first = game_deck_draw(&deck, &rng);
    const game_card_def_t *second = game_deck_draw(&deck, &rng);

    assert(first != NULL);
    assert(second != NULL);
    assert(strcmp(first->name, second->name) != 0);

    // Test reshuffle
    game_deck_discard(&deck, first);
    const game_card_def_t *third = game_deck_draw(&deck, &rng);
    assert(third != NULL);
    assert(strcmp(third->name, first->name) == 0);

    return 0;
}
