T18 Implementation Plan: Add NCurses Static Smoke Path

Intent

Goal: Implement the interactive NCurses interface wrapper. Translate keypresses into service commands and render the static match snapshots cleanly.

A terminal-based interface must render panels, stats, hands, and log lines on the screen using NCurses. To ensure robustness, we must build a clean rendering pipeline that accepts read-only snapshot structs, avoiding any direct modification of game state from within UI code.

Visual Layout Specification

The screen should be divided into sections:

  • Header: Shows active player name, phase, and turn instructions.
  • Players Panel: Shows names, levels, and power for all participants.
  • Hand Panel: Lists active player's cards, assigning quick-keys (e.g. 1-9) for selection.
  • Log Console: Displays the 5 most recent event descriptions.

#include "ncurses_client.h"
#include <ncurses.h>
#include <string.h>

void game_ui_init(void) {
    initscr();
    cbreak();
    noecho();
    keypad(stdscr, TRUE);
    curs_set(0);
    start_color();

    // Setup color pairs
    init_pair(1, COLOR_CYAN, COLOR_BLACK);
    init_pair(2, COLOR_RED, COLOR_BLACK);
    init_pair(3, COLOR_GREEN, COLOR_BLACK);
}

void game_ui_shutdown(void) {
    endwin();
}

void game_ui_render(const game_match_snapshot_t *snap) {
    if (!snap) return;
    clear();

    // Render Title Header
    attron(COLOR_PAIR(1) | A_BOLD);
    mvprintw(1, 2, "=== DUNGEON OF TECHNICAL DEBT v0.1 ===");
    attroff(COLOR_PAIR(1) | A_BOLD);

    mvprintw(2, 2, "Active Developer: %d | Phase: %d", snap->current_player_index, snap->phase);

    // Render Players Panel
    mvprintw(4, 2, "Developers List:");
    for (int i = 0; i < snap->player_count; i++) {
        char marker = (i == snap->current_player_index) ? '*' : ' ';
        mvprintw(5 + i, 4, "%c %s: Level %d | Power %d (Items equipped: %d)", 
                 marker, snap->players[i].name, snap->players[i].level, snap->players[i].power, snap->players[i].equipped_count);
    }

    // Render Battle Encounter area
    mvprintw(10, 2, "Encounter Area:");
    if (snap->has_active_encounter) {
        attron(COLOR_PAIR(2));
        mvprintw(11, 4, "Active Threat: %s (Power: %d)", snap->active_encounter_name, snap->active_encounter_power);
        attroff(COLOR_PAIR(2));
    } else {
        mvprintw(11, 4, "No active encounter. (Press 'k' to Kick Open Backlog)");
    }

    // Render active hand cards
    mvprintw(14, 2, "Your Hand (Treasure Items):");
    for (int i = 0; i < snap->hand_card_count; i++) {
        mvprintw(15 + i, 4, "[%d] %s", i + 1, snap->hand_card_names[i]);
    }

    // Controls footer
    mvprintw(22, 2, "Controls: [k] Kick Backlog | [r] Resolve | [1-9] Equip Item | [e] End Turn | [q] Quit");
    refresh();
}

int game_ui_get_input(void) {
    return getch();
}
