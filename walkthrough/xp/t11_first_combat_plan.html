T11 Implementation Plan: Resolve First Combat

Intent

Goal: Implement combat resolution rules. If a player's combat Power is greater than or equal to the monster's Power, they win, gain 1 Level and draw 1 Treasure reward. If they lose, they suffer "Bad Stuff" (level reduction or discard).

Combat resolution is the core interaction loop. Instead of forcing UI layers to inspect player structures and calculate levels, the domain layer must execute a single combat resolution function that returns a structured result struct detailing level shifts, items drawn, and state changes.

Combat Rules

  • Player Power: calculated via dad_player_get_power().
  • Monster Power: derived from the card definition's power value.
  • Winning: Player Power >= Monster Power. Level is incremented by 1 (max 10). Player draws 1 Treasure.
  • Losing: Level decremented by 1 (min 1). No treasure drawn.

Example Combat Implementation

Human-created file: domain/combat.c

#include "combat.h"

dad_combat_outcome_t dad_resolve_combat(dad_match_t *match, int player_index, const dad_card_def_t *monster) {
    dad_combat_outcome_t outcome = {0};
    if (!match || player_index < 0 || player_index >= match->player_count || !monster) {
        return outcome;
    }

    dad_player_t *player = &match->players[player_index];
    int player_power = dad_player_get_power(player);

    if (player_power >= monster->power) {
        // WIN
        outcome.win = true;
        dad_player_change_level(player, 1);
        outcome.level_change = 1;

        // Draw treasure
        const dad_card_def_t *treasure = dad_deck_draw(&match->treasure_deck, &match->rng);
        if (treasure) {
            dad_player_draw_to_hand(player, treasure);
            outcome.treasure_drawn = treasure;
        }
        
        if (dad_player_is_winner(player)) {
            outcome.match_ended = true;
            match->phase = PHASE_MATCH_OVER;
        }
    } else {
        // LOSS (Bad Stuff: Lose 1 Level)
        outcome.win = false;
        dad_player_change_level(player, -1);
        outcome.level_change = -1;
        outcome.treasure_drawn = NULL;
    }

    return outcome;
}

Example Combat Test

Human-created file: tests/domain/test_combat.c

#include "combat.h"
#include <assert.h>

int main(void) {
    // Setup minimal match state
    dad_class_def_t test_classes[6] = {
        {1, "QA", 0}, {2, "QA", 0}, {3, "QA", 0}, {4, "QA", 0}, {5, "QA", 0}, {6, "QA", 0}
    };
    dad_card_def_t test_cards[4] = {
        {"Legacy Monster", CARD_MONSTER, 4, 0, 1},
        {"Coffee Reward", CARD_TREASURE, 0, 0, 2},
        {"CI Curse", CARD_CURSE, 0, 0, 1},
        {"AI Intern", CARD_AI, 0, 0, 1}
    };
    dad_content_definitions_t content = {
        .classes = test_classes,
        .class_count = 6,
        .cards = test_cards,
        .card_count = 4
    };

    dad_match_t match;
    int class_selections[1] = {1};
    assert(dad_match_create(&match, &content, 42, 1, class_selections));

    // Player level 1, QA bonus 0, power = 1.
    // Monster power = 4. Player should lose.
    dad_card_def_t monster = {"Hard Bug", CARD_MONSTER, 4, 0, 1};
    
    dad_combat_outcome_t outcome = dad_resolve_combat(&match, 0, &monster);
    assert(!outcome.win);
    assert(outcome.level_change == -1); // Level remains 1 due to clamping
    assert(match.players[0].level == 1);

    // Level up manually to 5, power is now 5. Fight monster 4. Player should win.
    match.players[0].level = 5;
    outcome = dad_resolve_combat(&match, 0, &monster);
    assert(outcome.win);
    assert(outcome.level_change == 1);
    assert(match.players[0].level == 6);
    assert(outcome.treasure_drawn != NULL);

    return 0;
}
