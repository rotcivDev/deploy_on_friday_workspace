T17 Implementation Plan: Define Snapshot For Terminal Rendering

Intent

Goal: Implement a clean, read-only game_match_snapshot_t API. The snapshot must pack all active stats, player details, cards, events, and action availability flags into a pure data struct that the UI can render instantly without calculating gameplay rules.

In Clean Architecture, UI code must be a passive renderer. The terminal UI should never decide if an action is valid or compute current values by traversing active objects directly. Instead, the application layer generates a static snapshot detailing what to draw and what options are legal, isolating UI side-effects completely.

Out of scope: Actually drawing borders or capturing keyboard inputs (dealt with in T18).

Snapshot Fields Spec

The snapshot struct must hold:

  • Active player index and active phase name.
  • For each player: name, class name, Level, Power, Hand Count, Equipment Count, and list of equipped card names.
  • Details on active encounter (name, type, power if monster).
  • For the current player: list of card names in their hand.
  • Action availability flags (e.g. can_draw_encounter, can_resolve, can_equip, can_end_turn).

Refactor Slice

Example Snapshot Implementation

Human-created file: application/snapshot.c

#include "snapshot.h"
#include <string.h>

void game_match_get_snapshot(const game_match_t *match, game_match_snapshot_t *snap) {
    if (!match || !snap) return;

    memset(snap, 0, sizeof(game_match_snapshot_t));
    snap->player_count = match->player_count;
    snap->current_player_index = match->current_player_index;
    snap->phase = match->phase;

    // Populate players
    for (int i = 0; i < match->player_count; i++) {
        const game_player_t *p = &match->players[i];
        strncpy(snap->players[i].name, p->name, sizeof(snap->players[i].name) - 1);
        snap->players[i].level = p->level;
        snap->players[i].power = game_player_get_power(p);
        snap->players[i].hand_count = p->hand_count;
        snap->players[i].equipped_count = p->equipped_count;

        for (int k = 0; k < p->equipped_count; k++) {
            strncpy(snap->players[i].equipped_names[k], p->equipped[k]->name, 63);
        }
    }

    // Populate active encounter
    if (match->active_encounter) {
        snap->has_active_encounter = true;
        strncpy(snap->active_encounter_name, match->active_encounter->name, 63);
        snap->active_encounter_power = match->active_encounter->power;
    } else {
        snap->has_active_encounter = false;
    }

    // Populate active player hand card names
    const game_player_t *curr = &match->players[match->current_player_index];
    snap->hand_card_count = curr->hand_count;
    for (int i = 0; i < curr->hand_count; i++) {
        strncpy(snap->hand_card_names[i], curr->hand[i]->name, 63);
    }

    // Evaluate legality flags
    snap->can_draw_encounter = (match->phase == PHASE_START_TURN);
    snap->can_resolve_encounter = (match->phase == PHASE_RESOLVE_ENCOUNTER);
    snap->can_equip = (match->phase == PHASE_LOBBY_PLAY);
    snap->can_end_turn = (match->phase == PHASE_LOBBY_PLAY);
}

Example Snapshot Test

Human-created file: tests/application/test_snapshot.c

#include "snapshot.h"
#include <assert.h>

int main(void) {
    game_class_def_t test_classes[6] = {
        {1, "QA", 0}, {2, "QA", 0}, {3, "QA", 0}, {4, "QA", 0}, {5, "QA", 0}, {6, "QA", 0}
    };
    game_card_def_t test_cards[4] = {
        {"Monster A", CARD_MONSTER, 3, 0, 5},
        {"Equip A", CARD_EQUIPMENT, 0, 2, 5},
        {"Curse A", CARD_CURSE, 0, 0, 5},
        {"AI A", CARD_AI, 2, 0, 5}
    };
    game_content_definitions_t content = {
        .classes = test_classes,
        .class_count = 6,
        .cards = test_cards,
        .card_count = 4
    };

    game_match_t match;
    int class_selections[2] = {1, 2};
    assert(game_match_create(&match, &content, 42, 2, class_selections));

    game_match_snapshot_t snap;
    game_match_get_snapshot(&match, &snap);

    assert(snap.player_count == 2);
    assert(snap.can_draw_encounter == true);
    assert(snap.can_resolve_encounter == false);
    assert(snap.has_active_encounter == false);

    return 0;
}
