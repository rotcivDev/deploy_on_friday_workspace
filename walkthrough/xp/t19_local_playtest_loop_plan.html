T19 Implementation Plan: Integrate The Local Playtest Loop

Intent

Goal: Connect the game startup, command resolution, rendering, and bot moves into a playable local terminal loop.

A multiplayer game needs visual integration. By combining the interactive human input path and the deterministic bot AI turns into one cohesive loop, we enable real-time playtesting, balancing evaluations, and manual verification of v0.1 deliverables.

Implementation Story

Source backlog item: T19, R7, AR7, GD5.

Domain behavior served: Interactive play loop, bot decision sequences, and player action cycles.

User-visible outcome served: A user can run make run, select their class, play cards, watch the bots execute their turns, and play until someone wins.

Boundaries touched by the human: client/main.c, client/ncurses_client.c.

Out of scope: Persistence or database writing of session logs. Simple state loops only.

Playtest Flow Specification

The interactive main loop must follow this flow:

  1. Initialize database repository interface (or mocks if native dependencies are absent) and load content.
  2. Set up active game match using selected starting configs.
  3. Initialize NCurses screen layout.
  4. Loop:
    • Fetch active match snapshot.
    • Render snapshot to screen panels.
    • If active player is human: wait for keyboard command.
    • If active player is bot: wait 1 second, query bot AI decision, execute.
    • Run command and check for match victory.
  5. Close NCurses layout and display final stats.

Concrete Examples

Example Play Loop Main Stub

Human-created file: client/main.c

#include "game_service.h"
#include "bot_ai.h"
#include "ncurses_client.h"
#include <unistd.h>

int main(void) {
    // Stub databases
    dtd_class_def_t test_classes[6] = {
        {1, "Backend Dev", 1}, {2, "Frontend Dev", 0}, {3, "DevOps", 0},
        {4, "QA", 0}, {5, "Security", 0}, {6, "AI", 0}
    };
    dtd_card_def_t test_cards[4] = {
        {"Spooky Monster", CARD_MONSTER, 4, 0, 10},
        {"CI Curse", CARD_CURSE, 0, 0, 5},
        {"ThinkPad", CARD_EQUIPMENT, 0, 2, 10},
        {"Skill Book", CARD_TREASURE, 0, 1, 10}
    };
    dtd_content_definitions_t content = {
        .classes = test_classes,
        .class_count = 6,
        .cards = test_cards,
        .card_count = 4
    };

    dtd_game_service_t svc;
    dtd_service_init(&svc);

    // Human player index: 0. Bots indices: 1, 2.
    dtd_command_t start_cmd = {CMD_START_MATCH, 0, 0};
    dtd_service_execute(&svc, &start_cmd, &content);

    dtd_ui_init();

    bool running = true;
    while (running && svc.match_active && svc.match.phase != PHASE_MATCH_OVER) {
        dtd_match_snapshot_t snap;
        dtd_match_get_snapshot(&svc.match, &snap);

        dtd_ui_render(&snap);

        int active = snap.current_player_index;

        if (active == 0) {
            // Human player turn: process inputs
            int ch = dtd_ui_get_input();
            dtd_command_t cmd = {0};
            cmd.player_index = 0;

            if (ch == 'q') {
                running = false;
            } else if (ch == 'k') {
                cmd.type = CMD_KICK_BACKLOG;
                dtd_service_execute(&svc, &cmd, &content);
            } else if (ch == 'r') {
                cmd.type = CMD_RESOLVE_ENCOUNTER;
                dtd_service_execute(&svc, &cmd, &content);
            } else if (ch >= '1' && ch <= '9') {
                cmd.type = CMD_EQUIP_CARD;
                cmd.hand_index = ch - '1';
                dtd_service_execute(&svc, &cmd, &content);
            } else if (ch == 'e') {
                cmd.type = CMD_END_TURN;
                dtd_service_execute(&svc, &cmd, &content);
            }
        } else {
            // Bot player turn: simulate and log
            usleep(800000); // 800ms sleep so action is visible
            dtd_command_t cmd = dtd_bot_evaluate(&svc.match, active, BOT_LEGACY_MAINTAINER);
            dtd_service_execute(&svc, &cmd, &content);
        }
    }

    dtd_ui_shutdown();
    printf("Game Over! Thanks for playing Dungeon of Technical Debt.\n");
    return 0;
}
