T12 Implementation Plan: Resolve First Curses

Intent

Goal: Implement curse cards resolution logic. Support the v0.1 curses: Broken CI (skip next combat), Scope Creep (next monster gains +5 power), and Context Window Exceeded (discard half your hand rounded down).

Curses are negative effects that apply immediately when drawn from the Encounter deck. Some curses execute immediately and resolve (Context Window Exceeded), while others remain active until their expiry triggers (Broken CI, Scope Creep). We must manage this status state inside the player model.

Implementation Story

Source backlog item: T12, R5, AR4, SP2, GD3.

Domain behavior served: Drawing a curse, modifying player state flags, evaluating curse impacts during combat, and decreasing/expiring active curses.

User-visible outcome served: Players trigger curses that temporarily impair their stats or choices, reflecting software engineering challenges.

Boundaries touched by the human: domain/player.h, domain/player.c, domain/curse.h, domain/curse.c, tests/domain/test_curses.c.

Out of scope: Long-term persistent debts or stats debuffs that last past their specific trigger (e.g. Broken CI skips exactly 1 combat, then clears).

Curse Effects

  • Broken CI: Sets a skip_next_combat flag on the player. When combat starts, it resolves as a draw/skip and clears the flag.
  • Scope Creep: Sets a next_monster_power_bonus of 5 on the player. The next monster they battle has its Power temporarily increased by 5, then the bonus clears.
  • Context Window Exceeded: Immediately discards hand_count / 2 (rounded down) cards from the player's hand.

  2. Check that applying "Broken CI" sets skip_next_combat.

  4. Assert that this test fails to build.

Example Curse Implementation

Human-created file: domain/curse.c

#include "curse.h"
#include <string.h>

void dad_apply_curse(dad_match_t *match, int player_index, const dad_card_def_t *curse_card) {
    if (!match || player_index < 0 || player_index >= match->player_count || !curse_card) {
        return;
    }

    dad_player_t *player = &match->players[player_index];

    if (strcmp(curse_card->name, "Broken CI") == 0) {
        player->skip_next_combat = true;
    } else if (strcmp(curse_card->name, "Scope Creep") == 0) {
        player->next_monster_power_bonus = 5;
    } else if (strcmp(curse_card->name, "Context Window Exceeded") == 0) {
        // Discard half hand, rounded down
        int discard_count = player->hand_count / 2;
        for (int i = 0; i < discard_count; i++) {
            // Discard the last card for simplicity in v0.1
            player->hand_count--;
        }
    }
}

Example Curse Test

Human-created file: tests/domain/test_curses.c

#include "match.h"
#include "curse.h"
#include <assert.h>
#include <string.h>

int main(void) {
    dad_class_def_t test_classes[6] = {
        {1, "QA", 0}, {2, "QA", 0}, {3, "QA", 0}, {4, "QA", 0}, {5, "QA", 0}, {6, "QA", 0}
    };
    dad_card_def_t test_cards[4] = {
        {"Monster A", CARD_MONSTER, 5, 0, 5},
        {"Coffee", CARD_TREASURE, 0, 0, 5},
        {"Curse A", CARD_CURSE, 0, 0, 5},
        {"AI A", CARD_AI, 2, 0, 5}
    };
    dad_content_definitions_t content = {
        .classes = test_classes,
        .class_count = 6,
        .cards = test_cards,
        .card_count = 4
    };

    dad_match_t match;
    int class_selections[1] = {1};
    assert(dad_match_create(&match, &content, 42, 1, class_selections));

    dad_player_t *player = &match.players[0];

    // Check Context Window Exceeded
    // Give player 5 mock cards
    dad_card_def_t item = {"Item", CARD_TREASURE, 0, 0, 1};
    player->hand_count = 0;
    for(int i=0; i<5; i++) {
        dad_player_draw_to_hand(player, &item);
    }
    assert(player->hand_count == 5);

    dad_card_def_t curse_cw = {"Context Window Exceeded", CARD_CURSE, 0, 0, 1};
    dad_apply_curse(&match, 0, &curse_cw);
    // Should discard 5 / 2 = 2. Leaving 3 cards.
    assert(player->hand_count == 3);

    // Check Broken CI
    dad_card_def_t curse_ci = {"Broken CI", CARD_CURSE, 0, 0, 1};
    assert(!player->skip_next_combat);
    dad_apply_curse(&match, 0, &curse_ci);
    assert(player->skip_next_combat);

    return 0;
}
