T16 Implementation Plan: Produce Full-Match Simulation Transcript

Intent

Goal: Implement a non-interactive simulation target that uses a fixed seed and bot behaviors from T15 to run a complete 3-bot match from starting setup to Level 10 victory, writing the event log transcript to a text file.

Before launching an interactive terminal loop, we must verify the entire gameplay progression is robust and doesn't get stuck in deadlocks. Running a rapid, headless game simulation that finishes and logs all events proves compile-time correctness and provides a test fixture for verifying game balance.

Implementation Story

Source backlog item: T16, R6, R8, AR7, DEV4.

Domain behavior served: Long-term turn execution cycles. Victory and endgame processing.

User-visible outcome served: Developers can run a single command (make simulate) to verify the game compiles, starts, runs to completion, and behaves stably.

Boundaries touched by the human: client/simulation_main.c or subfolder, root Makefile updates, and transcript artifacts.

Out of scope: Live player keyboard event polling during simulation. Headless only.

Transcript Format Specification

The output transcript must log:

  • The match seed in the first line.
  • Initial player information.
  • Turn-by-turn logs listing drawn encounter cards, combat evaluations, level changes, and card play decisions.
  • The final winner and overall turn count.

Red Slice

  1. Write a check command that runs the simulation with seed 777 and asserts the output transcript file exists and contains the string "WINNER" and a valid turn count.
  2. Assert that this check fails before simulation logic is added.

Green Slice

  1. Add a simulation entry point target in CMake: dtd_simulator.
  2. Implement the loop in client/simulation_main.c that queries dtd_bot_evaluate() and executes commands using dtd_service_execute() until PHASE_MATCH_OVER is reached.
  3. Write the generated result events out to the transcript text file.
  4. Verify check commands pass successfully.

Refactor Slice

  1. Keep the simulator separate from NCurses client targets to ensure NCurses library errors don't prevent compiling the headless simulation.

Concrete Examples

Example Simulation Main

Human-created file: client/simulation_main.c

#include "game_service.h"
#include "bot_ai.h"
#include <stdio.h>

int main(int argc, char **argv) {
    uint64_t seed = 98765;
    if (argc > 1) {
        // Allow overriding seed from arguments
        sscanf(argv[1], "%lu", &seed);
    }

    FILE *out = fopen("walkthrough/simulation_transcript.txt", "w");
    if (!out) {
        perror("Failed to open transcript file");
        return 1;
    }

    fprintf(out, "MATCH SIMULATION SEED: %lu\n", seed);
    printf("Simulating game match with seed %lu...\n", seed);

    dtd_game_service_t svc;
    dtd_service_init(&svc);

    // Mock content database
    dtd_class_def_t test_classes[6] = {
        {1, "Backend Dev", 1}, {2, "Frontend Dev", 0}, {3, "DevOps", 0},
        {4, "QA", 0}, {5, "Security", 0}, {6, "AI", 0}
    };
    dtd_card_def_t test_cards[5] = {
        {"Legacy Spooky Monster", CARD_MONSTER, 4, 0, 10},
        {"Scope Creep", CARD_CURSE, 0, 0, 5},
        {"Broken CI", CARD_CURSE, 0, 0, 5},
        {"ThinkPad", CARD_EQUIPMENT, 0, 2, 10},
        {"Linux Skill", CARD_TREASURE, 0, 1, 10}
    };
    dtd_content_definitions_t content = {
        .classes = test_classes,
        .class_count = 6,
        .cards = test_cards,
        .card_count = 5
    };

    // Start Match
    dtd_command_t start_cmd = {CMD_START_MATCH, 0, 0};
    dtd_command_result_t res = dtd_service_execute(&svc, &start_cmd, &content);

    int limit = 0;
    while (svc.match_active && svc.match.phase != PHASE_MATCH_OVER && limit < 500) {
        int active_idx = svc.match.current_player_index;
        
        // Evaluate bot decision
        dtd_command_t cmd = dtd_bot_evaluate(&svc.match, active_idx, BOT_LEGACY_MAINTAINER);
        
        res = dtd_service_execute(&svc, &cmd, &content);
        if (res.status == CMD_OK) {
            for (int i = 0; i < res.event_count; i++) {
                fprintf(out, "[TURN %d][PLAYER %d] %s\n", limit, res.events[i].player_index, res.events[i].message);
            }
        } else {
            fprintf(out, "[ERROR] Command failed with status %d at turn %d\n", res.status, limit);
            break;
        }

        limit++;
    }

    fprintf(out, "SIMULATION FINISHED. TURNS ELAPSED: %d\n", limit);
    for (int i = 0; i < svc.match.player_count; i++) {
        fprintf(out, "Player %s reached level %d\n", svc.match.players[i].name, svc.match.players[i].level);
    }
    fclose(out);

    printf("Simulation completed successfully. Output saved to walkthrough/simulation_transcript.txt\n");
    return 0;
}
