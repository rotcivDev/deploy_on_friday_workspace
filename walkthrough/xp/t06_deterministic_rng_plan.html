T06 Implementation Plan: Introduce Deterministic RNG

Intent

Goal: Implement a small, pure C17 pseudorandom number generator (PRNG) struct and associated utility functions. Stop using global rand() or srand(), ensuring all card shuffles, bot choices, and game matches can be fully replayed from an initial seed.

In multiplayer terminal card games, debugging game rules and bot behavior is extremely difficult when RNG is non-deterministic. By carrying an explicit state struct representing the RNG state inside the match state, we guarantee that compiling and running the game with the same seed yields the exact same execution trace across platforms.

Implementation Story

Domain behavior served: Repeatable card draws, deterministic card shuffles, and reproducible bot decision paths.

User-visible outcome served: Matches can be recorded, stored as logs with a seed, and replayed step-by-step for bug reporting and resolution.

Boundaries touched by the human: domain/rng.h, domain/rng.c, tests/domain/test_rng.c.

Out of scope: Live system timestamps or hardware randomness (e.g. /dev/urandom). Only use seed numbers.

Design Notes

We will implement a standard Linear Congruential Generator (LCG) using parameters from a popular standard (like MMIX or Numerical Recipes) or PCG-32. Since we need simple deterministic logic, an LCG is perfect:

next_state = (multiplier * state + increment) % modulus

    uint64_t state;
} game_rng_t;

void game_rng_init(game_rng_t *rng, uint64_t seed);

Example RNG Implementation

Human-created file: domain/rng.c

#include "rng.h"

// standard LCG parameters (MMIX)
static const uint64_t MULTIPLIER = 6364136223846793005ULL;
static const uint64_t INCREMENT = 1442695040888963407ULL;

void game_rng_init(game_rng_t *rng, uint64_t seed) {
    if (rng) {
        rng->state = seed;
    }
}

uint32_t game_rng_next(game_rng_t *rng) {
    if (!rng) return 0;
    rng->state = (MULTIPLIER * rng->state + INCREMENT);
    return (uint32_t)(rng->state >> 32);
}

uint32_t game_rng_range(game_rng_t *rng, uint32_t min, uint32_t max) {
    if (!rng || min >= max) return min;
    uint32_t range = (max - min + 1);
    return min + (game_rng_next(rng) % range);
}

Example RNG CTest

Human-created file: tests/domain/test_rng.c

#include "rng.h"
#include <assert.h>

int main(void) {
    game_rng_t rng1;
    game_rng_t rng2;

    game_rng_init(&rng1, 42);
    game_rng_init(&rng2, 42);

    // Verify same seed produces identical sequence
    for (int i = 0; i < 20; i++) {
        assert(game_rng_next(&rng1) == game_rng_next(&rng2));
    }

    // Verify different seeds produce different outputs
    game_rng_init(&rng2, 99);
    bool different = false;
    for (int i = 0; i < 5; i++) {
        if (game_rng_next(&rng1) != game_rng_next(&rng2)) {
            different = true;
            break;
        }
    }
    assert(different);

    // Verify range constraints
    for (int i = 0; i < 100; i++) {
        uint32_t val = game_rng_range(&rng1, 10, 20);
        assert(val >= 10 && val <= 20);
    }

    return 0;
}
