T10 Implementation Plan: Implement Power and Level Invariants

Intent

Goal: Implement level progression rules and invariants. Ensure levels are clamped strictly between Level 1 and Level 10, and model the victory trigger when Level 10 is reached.

In turn-based RPG rulesets, stats must respect strict mathematical invariants. A player's Level must never fall below 1 or exceed 10. When a player hits level 10, the match must immediately conclude and declare them the winner. These rules must be implemented via pure functions.

Human-created file: domain/player.c (implementation)

#include "player.h"

void dad_player_change_level(dad_player_t *player, int delta) {
    if (!player) return;
    int temp = player->level + delta;
    if (temp < 1) {
        player->level = 1;
    } else if (temp > 10) {
        player->level = 10;
    } else {
        player->level = temp;
    }
}

bool dad_player_is_winner(const dad_player_t *player) {
    return player && player->level == 10;
}

Example Invariants Test

Human-created file: tests/domain/test_invariants.c

#include "player.h"
#include <assert.h>

int main(void) {
    dad_player_t player;
    dad_player_init(&player, "QA intern", 0);

    assert(player.level == 1);
    
    // Test clamping at bottom
    dad_player_change_level(&player, -5);
    assert(player.level == 1);

    // Test level up
    dad_player_change_level(&player, 4);
    assert(player.level == 5);
    assert(!dad_player_is_winner(&player));

    // Test clamping at top
    dad_player_change_level(&player, 6);
    assert(player.level == 10);
    assert(dad_player_is_winner(&player));

    dad_player_change_level(&player, 1);
    assert(player.level == 10);

    return 0;
}
