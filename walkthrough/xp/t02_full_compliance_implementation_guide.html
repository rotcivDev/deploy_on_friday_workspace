T02 Full Compliance Implementation Guide

Purpose

Goal: make the T02 build skeleton fully compliant by preserving fast pure tests while keeping PostgreSQL and NCurses available as explicit native dependency targets.

T02 is not about gameplay yet. It proves that future domain rules can be tested in pure C17 without database, terminal UI, sockets, pthreads, or filesystem runtime concerns leaking into the inner layers.

The current working build already has the correct basic target names and passing smoke tests. The remaining compliance gap is configurability: a developer without PostgreSQL or NCurses development headers must still be able to run the fast domain/application feedback loop.

Key Compliance Points

  1. Fast targets are unconditional. game_domain, game_application, game_tests_domain, and game_tests_application must configure and build with only a C17 compiler and CMake.
  2. Native dependency targets are explicit. PostgreSQL and NCurses targets should be opt-in or guarded so missing development headers do not break the fast test path.
  3. make test builds only fast tests. It should not compile DB or UI targets as a side effect.
  4. make build-all proves native integrations. DB/UI compilation belongs behind an explicit command for machines with those dependencies installed.
  5. Forbidden includes stay isolated. Domain and application source must not include libpq-fe.h, ncurses.h, socket headers, or pthread headers.
  6. CTest names match the T02 contract. The smoke tests are domain_smoke and application_smoke.
  7. The build exports editor evidence. compile_commands.json should be generated so header-path issues can be diagnosed from the actual build graph.

  • Document which command proves which boundary.

Final CMake Shape

This is the recommended final configuration shape for T02 compliance. It keeps pure targets available on every machine and makes DB/UI targets explicit.

cmake_minimum_required(VERSION 4.3)
project(GameCore C)

set(CMAKE_C_STANDARD 17)
set(CMAKE_C_STANDARD_REQUIRED ON)
set(CMAKE_C_EXTENSIONS OFF)
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)

add_compile_options(-Wall -Wextra -Werror -pedantic)

option(GAME_BUILD_DB_ADAPTER "Build PostgreSQL infrastructure adapter" OFF)
option(GAME_BUILD_NCURSES_CLIENT "Build NCurses client" OFF)

enable_testing()

add_library(game_domain
    domain/game_domain_smoke.c
)
target_include_directories(game_domain PUBLIC domain)

add_library(game_application
    application/game_application_smoke.c
)
target_include_directories(game_application PUBLIC application)
target_link_libraries(game_application PUBLIC game_domain)

add_executable(game_tests_domain
    tests/domain/test_domain_smoke.c
)
target_link_libraries(game_tests_domain PRIVATE game_domain)
add_test(NAME domain_smoke COMMAND game_tests_domain)

add_executable(game_tests_application
    tests/application/test_application_smoke.c
)
target_link_libraries(game_tests_application PRIVATE game_application game_domain)
add_test(NAME application_smoke COMMAND game_tests_application)

if(GAME_BUILD_DB_ADAPTER)
    find_package(PostgreSQL REQUIRED)

    add_library(game_infrastructure_db
        infrastructure/db/postgresql_content_repository_smoke.c
    )
    target_include_directories(game_infrastructure_db PRIVATE
        infrastructure/db
        ${PostgreSQL_INCLUDE_DIRS}
    )
    target_link_libraries(game_infrastructure_db PRIVATE
        game_application
        game_domain
        ${PostgreSQL_LIBRARIES}
    )
endif()

if(GAME_BUILD_NCURSES_CLIENT)
    find_package(Curses REQUIRED)

    if(NOT TARGET game_infrastructure_db)
        message(FATAL_ERROR
            "GAME_BUILD_NCURSES_CLIENT requires GAME_BUILD_DB_ADAPTER for the current T02 client link shape."
        )
    endif()

    add_executable(game_client_ncurses
        client/main.c
    )
    target_include_directories(game_client_ncurses PRIVATE
        client
        ${CURSES_INCLUDE_DIR}
    )
    target_link_libraries(game_client_ncurses PRIVATE
        game_application
        game_domain
        game_infrastructure_db
        ${CURSES_LIBRARIES}
    )
endif()
Important: the DB and NCurses options default to OFF so a clean contributor machine can still configure and run fast tests. Native integration work turns them on explicitly.

Final Makefile Shape

This Makefile keeps the user-facing workflow simple while separating fast feedback from native dependency checks.

.PHONY: configure build test clean configure-all build-all test-all run

BUILD_DIR := build
NATIVE_BUILD_DIR := build-native

FAST_CMAKE_FLAGS := \
	-DGAME_BUILD_DB_ADAPTER=OFF \
	-DGAME_BUILD_NCURSES_CLIENT=OFF

NATIVE_CMAKE_FLAGS := \
	-DGAME_BUILD_DB_ADAPTER=ON \
	-DGAME_BUILD_NCURSES_CLIENT=ON

configure:
	cmake -S . -B $(BUILD_DIR) $(FAST_CMAKE_FLAGS)

build: configure
	cmake --build $(BUILD_DIR) --target game_tests_domain game_tests_application

test: build
	ctest --test-dir $(BUILD_DIR) --output-on-failure

configure-all:
	cmake -S . -B $(NATIVE_BUILD_DIR) $(NATIVE_CMAKE_FLAGS)

build-all: configure-all
	cmake --build $(NATIVE_BUILD_DIR)

test-all: build-all
	ctest --test-dir $(NATIVE_BUILD_DIR) --output-on-failure

run: build-all
	./$(NATIVE_BUILD_DIR)/game_client_ncurses

clean:
	cmake -E rm -rf $(BUILD_DIR) $(NATIVE_BUILD_DIR)

The main policy decision is that make test proves the T02 fast path, while make build-all proves the native PostgreSQL and NCurses path.

Review Gates

Fast Path

make clean
make test
ctest --test-dir build --output-on-failure

Expected result: only domain_smoke and application_smoke are required, and no PostgreSQL or NCurses development package is needed.

Native Dependency Path

make build-all
make test-all

Expected result: DB and NCurses targets compile on a machine with the required development headers installed.

Boundary Search

rg -n '#include\s*[<"](libpq-fe\.h|ncurses\.h|pthread\.h|sys/socket\.h|netinet/in\.h)' \
  domain application tests infrastructure client

Expected result: libpq-fe.h appears only in infrastructure, ncurses.h appears only in client, and no forbidden header appears in domain or application.

Completion Criteria

  • make test passes from a clean tree using the fast configuration.
  • make test does not compile DB or NCurses targets.
  • make build-all is the explicit command that requires PostgreSQL and NCurses development headers.
  • game_tests_domain links only game_domain.
  • game_tests_application links only game_application and game_domain.
  • Domain and application source contain no PostgreSQL, NCurses, pthread, or socket includes.
  • compile_commands.json is generated for both fast and native build directories.
  • The human implementation notes mention T02 and record whether make build-all was run on a host with native dependencies installed.
