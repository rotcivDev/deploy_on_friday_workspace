Walkthrough Index

Extension Outline: The AI New Era

Patch type: AI-hype and agentic-systems extension. Compatibility tags: ai, high-chaos, community, infrastructure.

Theme Promise

Players deal with agents, hallucinations, prompt chains, vector databases, AI influencers, datacenter credits, and the tension between useful automation and catastrophic overconfidence.

New Content Direction

  • Monsters: Infinite Agent Loop, Hallucinated Function, Recursive Prompt Chain, Autonomous Junior Developer.
  • Equipment: Local LLM Cluster, Prompt Library, Vector Database, Agent Framework.
  • Curses: Context Window Exceeded, Hallucinated Documentation, Token Budget Panic.
  • Events: Model Upgrade Day, Hacker News Front Page, AI Safety Review.
  • Achievements: Win With Open Weights, Cancel A Hallucination, Defeat The Singularity.

Mechanic Outline

Use inference effects that trade deterministic risk for large rewards. The RNG seed must fully determine all AI-chaos outcomes.

Deck Recipe Impact

  • High chaos, high Influence interaction.
  • Strong late-game content that should not flood early Encounter draws.
  • Mixes especially well with The Punch Card Era and The SaaS Bubble.

Release Gate

  • AI cards do not bypass server authority.
  • Every inference effect emits an auditable command result.
  • Mixed decks cap early high-power AI monsters unless an advanced recipe is selected.
