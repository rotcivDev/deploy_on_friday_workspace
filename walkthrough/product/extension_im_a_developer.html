Extension Outline: I'm a Developer

Patch type: developer-identity extension. Compatibility tags: career, community, workflow, tools.

Theme Promise

This patch focuses on the daily identity of developers: editor wars, code reviews, pull requests, debugging rituals, rubber ducking, impostor syndrome, and the strange pride of making something work at 2 a.m.

New Content Direction

  • Monsters: Reviewer With 87 Comments, Off-By-One Phantom, Works On My Machine, Dependency Upgrade.
  • Equipment: Favorite Editor, Debugger Mastery, Mechanical Keyboard, Rubber Duck.
  • Curses: Impostor Syndrome, Merge Conflict, Tabs Versus Spaces.
  • Events: Pair Programming Session, Refactoring Friday, Open Source Maintainer Appears.
  • Achievements: Ship With Tests, Win After A Merge Conflict, Defeat Off-By-One Phantom.

Mechanic Outline

Use focus as a light resource or status flag for cards that reward disciplined play. Avoid adding a second economy until Influence and Power are stable.

Deck Recipe Impact

  • Best candidate for the first sample extension because it reinforces the main deck.
  • Adds approachable cards with low rules complexity.
  • Mixes with every other extension as the human-scale career layer.

Release Gate

  • No extension card requires a special UI screen.
  • At least one card improves cooperation and one card enables sabotage.
  • Main plus this extension remains suitable for first-time players.
